1. Aim & Objective

To build and evaluate a privacy-preserving, auditable educational application that:

  • Transcribes multi-format spoken lecture audio (WAV, MP3, M4A, FLAC) on CPU using quantized speech recognition.
  • Generates concise, factual extractive summary notes while eliminating generative hallucination risks.
  • Automatically formulates 5-question multiple-choice cloze quizzes with domain-relevant in-lecture distractors.
  • Provides instant scoring alongside verbatim source-sentence citations for complete auditability.

2. Tools & Technologies

  • Application Framework: Python 3.10+, Streamlit, Streamlit Community Cloud
  • Speech Recognition (ASR): faster-whisper (CTranslate2, int8 CPU inference, Voice Activity Detection)
  • Audio Handling: PyAV (av) with cross-version argument wrapper compatibility
  • Generative LLM (Optional): bharatgenai/Param-1 via Hugging Face Transformers pipeline
  • Benchmarking Suite: Python deterministic smoke test framework (evaluate.py)

3. System Pipeline

  1. Input: User uploads lecture audio or enters/pastes lecture text.
  2. ASR Transcription: faster-whisper transcribes audio into text, displaying detected language and confidence.
  3. Extractive Ranking: Scores sentences by content word frequency normalized by length with an introductory bias (+0.15).
  4. Cloze Generation: Extracts key domain concepts (length ≥ 5) as blanks and pools distractors from the lecture vocabulary.
  5. Automated Grading: Validates user selections, tallies scores, and displays exact source sentences for verification.
